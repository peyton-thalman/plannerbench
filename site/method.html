Method

A benchmark is only as good as its answer key

In short

If the key is wrong, you’re grading the model on your own bug. So the engine that writes the key is checked by people and programs that didn’t write it, and one script rebuilds every number on this site from the raw replies.

The proof, layer by layer

Independent checks, with their scores

Gates

No question ships unless all of these pass

./reproduce.sh reruns every one of them and must end with REPRODUCED.

  1. Published examples. Cases whose answers come straight from IRS, SSA and CMS tables must match exactly.
  2. Two independent programs. The planning engine and a separately written checker compute every answer. They agree on all — questions.
  3. Rules that must always hold. Thousands of random households test things like “more income never lowers tax” and “waiting a month never lowers a Social Security check.”
  4. Dataset health. No duplicates, and no task where one answer is common enough to guess.
  5. Human audit. Random cases come with worked solutions a CPA can check with a calculator. (Outside sign-off is still open.)
  6. An outside tax model. PolicyEngine-US, open-source and written by others, recomputes every tax answer.
  7. Same model, two routes. —
  8. A held-out set. Private questions from a secret seed pass the same checks and are never published, so a model that trained on the public set still meets new ones, and nothing is tuned on them.

When models disagree with the key, the source decides, not the models. Models from several labs agreed with each other and against the key on the senior deduction; the IRS form, and separately PolicyEngine, showed the key was right. Several also answered Medicare premiums ten cents above the key; SSA’s 2026 table matches the key to the cent.

Statistics

How the numbers are reported

  • Every accuracy carries a 95% interval: the range the true score likely sits in. Small runs show wide bands on purpose.
  • Comparisons are paired. “Alone vs. with tools” asks the same model the same questions, and counts how many flipped each way (McNemar’s test).
  • Failures are their own bucket. A reply that ran out of tokens is published and counted as not right, never quietly dropped.
  • Mistakes are priced. Each wrong number is also scored in dollars a year off, so a ten-cent miss and a $9,000 miss don’t count the same.
  • Hosts are pinned. Every outside model runs on one named host with data collection off; the private set never goes to free endpoints.
