AI on its own · findings 1 and 2

AI gets one rule right. When rules meet, it depends which AI you ask.

The plain answer

Ask about one well-known rule and the best AIs I tested are almost always right. Ask a question where several rules meet, the way they do in a real household, and scores spread out: in my newer, harder set, GPT-6.1 Sol got — right and — cheap and free models scored under 30%. ChatGPT on a regular subscription, tested separately, got —. In the first test, many models made the same mistake on a tax rule that is new since 2025.

      Why it isn’t in the tables above. The setup differs. The other models got one message per question, at low reasoning effort with a —-token reply limit. ChatGPT ran at — effort with no limit, and I sent the questions in small batches, each to be answered as its own chat. In the regular ChatGPT app the model can choose to run code; here it was told not to, like every other model on this page.

      How the ChatGPT run was done

      The questions went through Codex, OpenAI’s coding app, which runs on a ChatGPT subscription, so no per-question fee and no developer account were involved. Each batch had a handful of questions with their answers removed and their names replaced by plain codes, and the instruction to answer each as its own chat, showing the reasoning, with no code, calculator, web search or other files. A first attempt was thrown out because most replies were a bare final number with no reasoning, which isn’t how ChatGPT answers a person. In the second attempt, one session refused a whole batch and some questions were skipped; those were asked again in a fill-in batch, and one first-test question still went unanswered, so its first-test score is out of —. Within a batch, earlier questions stayed in the conversation, which a fresh chat wouldn’t have. Ranges (95%): newer set —; one rule —. Grading checks are on How I checked.

      What the results mean, and what they don’t

      • A new rule was a measured gap. Shown the IRS’s instructions for the 2025 senior deduction, Claude Sonnet 5.5 went from — on those questions. Most other wrong answers matched no known misreading, so I can’t say what caused them; arithmetic slips happen too (one shows up on the wrong-facts page).
      • It isn’t one company’s blind spot. In the first test, DeepSeek and GLM made the same senior-deduction misreading as Claude. Some misses show models using an older version of a rule: gpt-oss-120b used the withdrawal table replaced in 2022 on every withdrawal question it got wrong.
      • Price per word misleads. A model that’s cheap to run can cost more per right answer if it thinks so long it never answers. The cost columns are in the full tables above.
      • It’s still small. —–— questions per task per model in the first test, — in the newer set. A gap of a few points is within the noise; the ranges show how much.
