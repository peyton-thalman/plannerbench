In short

A lot of reading now starts with a model. So every page here has a plain-text twin, no JavaScript needed, and nothing in it is hidden from the human version.

The “For AI readers” link at the top right of every page brings you here. This page is a list of plain-text files, not a different view of the page you were on; “Human” takes you back to the normal pages.

Start here

Each file is made from the finished pages every time the site is built, so the numbers match what people see.
